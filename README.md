
# Project 8 - Expense Tracker

A simple Python Expense Tracker application that runs in the terminal.

## Features
- Add expenses with name, amount and category.
- View all recorded expenses.
- Calculate total money spent.
- Calculate total spending by category.
- Save expenses in expenses.txt.
- Load previously saved expenses when restarting.

## Concepts Used
- Lists and dictionaries
- Functions
- While loops
- If-else statements
- File handling
- Type casting using float()
- Try-except error handling

## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run: python expense_tracker.py
